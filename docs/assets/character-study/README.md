# Studio Ranger — geometria reale

Sorgenti 864f97f, stesso setup luce/camera per corpo condiviso precedente e
prima traduzione Ranger originale. Chromium SwiftShader, 1200×960, DPR 1.
Quattro pose: base, risonanza, preparazione tiro e retro.

È una scena di authoring, non la camera del gioco. Il corpo a sinistra è il
precedente modello condiviso del prototipo Mythwood, non una ricostruzione del
vecchio Bosco pubblicato. Non usare come falso confronto di due giochi completi.

Sorgenti originali in src/visuals/ranger.js; niente acquisti o conversione
automatica del concept. Resa ancora semplificata. Hash ed esiti in
docs/verification/character-latest.json. Ripetere con npm run test:character.
