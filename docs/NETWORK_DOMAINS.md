# Domini proposti per le impostazioni Cloud

Non è una modifica alla configurazione né un elenco di integrazioni già attive.
Mantenere le regole esistenti. Aggiungere senza schema HTTPS, porta o percorso.
La nuova build locale non richiede questi servizi per giocare; servono per
installazione, documentazione, ricerca e lavoro sulle integrazioni future.

GitHub, registry.npmjs.org e diversi domini di distribuzione erano già inclusi
nel preset dei package manager. Le regole per social, Claude, Mimmo e il progetto
Supabase sono state gestite separatamente dal proprietario: non sostituirle.

Prima di installare i browser Playwright fuori dalla macchina predisposta,
verificare gli host di download effettivi e richiedere gli eventuali domini
aggiuntivi. Redirect/CDN non sono autorizzati automaticamente da un dominio apex.
Non concedere accesso globale o wildcard a un intero provider per un solo download.

Un dominio consentito non fornisce autenticazione, autorizzazione alla spesa o
diritto di pubblicare contenuti. Leggere licenze e condizioni prima dell'uso.
